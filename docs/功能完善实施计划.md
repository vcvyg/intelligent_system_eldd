# 智慧养老系统 - 功能完善实施计划

## 一、数据库关联关系设计

### 1.1 已创建的关联表

#### 1. elderly_family_relation - 老人子女关系表
- 功能: 记录老人与子女的关联关系
- 支持: 一个老人关联多个子女,主要联系人标记
- 字段: 老人ID、子女用户ID、关系类型、是否主要联系人

#### 2. elderly_medical_relation - 老人医护关系表
- 功能: 记录老人与医护人员的分配关系
- 支持: 多对多关系,主治医生标记
- 字段: 老人ID、医护人员ID、是否主治医生、分配日期

#### 3. medical_schedule - 医护排班表
- 功能: 医护人员排班管理
- 支持: 早班/中班/晚班/夜班
- 字段: 医护人员ID、排班日期、班次类型、时间段、状态

#### 4. alert_notification - 预警通知记录表
- 功能: 记录预警发送的通知
- 支持: 短信/邮件/系统通知
- 字段: 预警ID、接收者ID、通知类型、联系方式、发送状态

#### 5. medical_task - 医护任务表
- 功能: 医护人员的日常任务管理
- 支持: 定期检查/用药提醒/康复训练等
- 字段: 老人ID、医护人员ID、任务类型、优先级、状态

### 1.2 设备绑定关系
- 已有: device_info表中的elderly_id字段实现设备与老人绑定
- 支持: 一个老人绑定多个设备

### 1.3 预警关联关系
- 已有: alert_record表中的elderly_id和device_id实现关联
- 新增: alert_notification表实现预警通知记录

## 二、功能模块开发优先级

### 阶段一: 基础关联关系管理(最高优先级)

#### 1. 老人信息管理增强 ⭐⭐⭐⭐⭐
**位置**: admin-elderly.html页面
**新增功能**:
- 老人详情页面添加"关联管理"标签页
  - 关联子女管理(添加/删除子女,设置主要联系人)
  - 关联医护人员(分配/调整医护人员,设置主治医生)
  - 绑定设备管理(查看/添加/解绑设备)

**前端页面**:
- 修改elderly_info页面,添加关联管理功能
- 新增关联管理弹窗

**后端接口**:
- POST /api/admin/elderly/{id}/family - 添加子女关联
- DELETE /api/admin/elderly/{id}/family/{familyId} - 删除子女关联
- POST /api/admin/elderly/{id}/medical - 分配医护人员
- DELETE /api/admin/elderly/{id}/medical/{medicalId} - 取消医护分配

#### 2. 设备管理增强 ⭐⭐⭐⭐⭐
**位置**: admin-devices.html页面
**新增功能**:
- 设备绑定老人功能
- 设备详情显示绑定的老人信息

**后端接口**:
- PUT /api/admin/devices/{id}/bind - 绑定设备到老人
- PUT /api/admin/devices/{id}/unbind - 解绑设备

### 阶段二: 预警通知系统(高优先级)

#### 3. 预警自动通知 ⭐⭐⭐⭐
**功能描述**:
- 当产生预警时,自动通知老人的所有关联子女
- 支持短信和邮件双通道通知
- 记录通知发送状态

**后端开发**:
- 预警触发时自动查询关联子女
- 调用短信/邮件服务发送通知
- 记录到alert_notification表

**所需服务**:
- 短信服务: 阿里云短信/腾讯云短信
- 邮件服务: SMTP邮件发送

**后端接口**:
- POST /api/admin/alerts/{id}/notify - 手动发送预警通知
- GET /api/admin/alerts/{id}/notifications - 查询预警通知记录

### 阶段三: 医护人员功能(中优先级)

#### 4. 医护排班管理 ⭐⭐⭐
**新增页面**: admin-medical-schedule.html
**功能**:
- 医护人员排班日历视图
- 添加/编辑/删除排班
- 查看当日值班医护人员
- 请假/调班管理

**后端接口**:
- GET /api/admin/medical/schedule - 查询排班列表
- POST /api/admin/medical/schedule - 添加排班
- PUT /api/admin/medical/schedule/{id} - 修改排班
- DELETE /api/admin/medical/schedule/{id} - 删除排班

#### 5. 医护任务管理 ⭐⭐⭐
**新增页面**: admin-medical-tasks.html (管理端) / medical-tasks.html (医护端)
**功能**:
- 创建医护任务
- 分配任务给医护人员
- 医护人员查看自己的任务列表
- 任务完成记录

**后端接口**:
- GET /api/admin/medical/tasks - 查询任务列表
- POST /api/admin/medical/tasks - 创建任务
- PUT /api/medical/tasks/{id}/complete - 完成任务

## 三、技术实现要点

### 3.1 短信/邮件通知集成
**推荐方案**:
- 短信: 阿里云短信服务 (性价比高,稳定)
- 邮件: Spring Boot Mail + SMTP

**配置**:
```yaml
# application.yml
spring:
  mail:
    host: smtp.qq.com
    username: your-email@qq.com
    password: your-smtp-password
```

### 3.2 关联关系处理
- 使用多对多中间表
- 注意级联删除问题
- 添加索引提升查询性能

### 3.3 实时通知
- WebSocket推送预警信息
- 轮询机制作为降级方案

## 四、实施建议

### 优先实现顺序:
1. **第一步**: 执行 `add_relationship_tables.sql` 创建关联表
2. **第二步**: 实现老人-子女-医护的关联管理(阶段一)
3. **第三步**: 实现设备绑定功能(阶段一)
4. **第四步**: 实现预警通知系统(阶段二)
5. **第五步**: 根据需要逐步完善其他功能

### 开发建议:
- 采用增量开发,每完成一个功能就测试一个
- 先实现后端接口,再开发前端页面
- 关联关系管理是核心,优先实现
- 通知系统可以先做系统内通知,短信/邮件后续集成
